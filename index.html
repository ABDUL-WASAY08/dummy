How to Deploy Your Web Application to Microsoft Azure

By DevOps Team • October 2026 • 6 min read

Deploying your web application to the cloud is a crucial step to making it accessible worldwide. Microsoft Azure offers robust, scalable, and developer-friendly environments to host everything from simple static sites to complex microservices.

In this guide, we will walk through deploying a standard web application to Azure using the Azure App Service and the Azure CLI.

Prerequisites

Before you begin, ensure you have the following ready:

  • An active Microsoft Azure Account (Free tier works great!).
  • The Azure CLI installed on your local machine.
  • Your web application code ready in a local project folder.
Pro Tip: If you are working with Node.js, Python, or .NET, Azure App Service automatically detects your runtime stack and provisions the proper server environment.

Step 1: Log in to Azure via CLI

Open your terminal and authenticate your local machine with your Azure account by running the login command:

az login

This will open a browser window asking you to sign in with your Azure credentials.

Step 2: Create a Resource Group

Resource groups act as logical containers for your Azure resources. Create a new resource group in your preferred region (e.g., East US):

az group create --name myResourceGroup --location eastus

Step 3: Create an App Service Plan

An App Service plan defines the region, size, and features of the web server farm hosting your app. Create a free tier plan (F1) using:

az appservice plan create --name myAppServicePlan --resource-group myResourceGroup --sku F1 --is-linux

Step 4: Create and Deploy the Web App

Now, create the actual Web App instance. Replace myUniqueAppName with a globally unique name for your application:

az webapp create --resource-group myResourceGroup --plan myAppServicePlan --name myUniqueAppName --runtime "NODE:18-lts"

Finally, push your code directly to the app using local Git deployment or ZIP deployment:

az webapp up --resource-group myResourceGroup --name myUniqueAppName

Conclusion

Congratulations! Your application is now live on the cloud. You can visit your newly deployed service by navigating to:

https://myUniqueAppName.azurewebsites.net

From here, you can set up custom domains, scale your computing tiers, and configure CI/CD pipelines via GitHub Actions for automated future deployments.
